## Outcome and observations

M3Q A/B both emitted0 approach warnings:31 positive target-keyframe misses,
8 true negatives,5 unknown targets,150 silent frames. RootSIFT is rejected:
it is slower and frequently lacks the unchanged9-point source minimum. Do not
optimize or promote that path.18/31 first vetoes were unresolved identity rivals.

Separate object identity from displacement/expansion measurement. Identity age,
cohort survival and a tracker integer are not sufficient evidence. A current
warning still needs actual current/fresh/anchor pixel measurements and all
existing geometry/camera/temporal floors.

### Bounded design comparison before new RGB/results

Exact global one-to-one interval assignment was examined on OLD development
M3Q A matrices, not a new model run:185 fields,6421 edges,4451 unknown[0,1].
294 supported pairs appear in maximum-lower-score assignments, but NONE has
the unchanged.08 robust margin against every alternative upper-score assignment
altering that target (unmatched dummies retained). Do not spend a full trial
merely replacing the row matcher with Hungarian/global intervals.

Likewise, an edge failing measurement-quality policy is not necessarily a
different physical object. Do not set its uncertainty upper bound to0 merely
because its bbox growth or source detail cannot yield an accepted measurement.

DINOv2 object descriptors were considered, not downloaded or implemented.
Generic feature similarity is not certified instance identity. Prefer a smaller
existing independently measured identity cue before adding a model/dependency.
Research: [DINOv2 official](https://github.com/facebookresearch/dinov2),
[generalizable object ReID limitations](https://openaccess.thecvf.com/content/ICCV2025/papers/Huang_Generalizable_Object_Re-Identification_via_Visual_In-Context_Prompting_ICCV_2025_paper.pdf).

Existing T (CohortWindowLoom) already combines reciprocal camera-corrected box
links with coarse visual appearance. On OLD data, same-ID plus supported fresh/
anchor measurements gives3 possible expansion events, NOT3 validated successes.
All3 have appearance-only uninterrupted chains. Separate reviewer independently
reconstructed13 adjacent edges from16 original source PNGs: native2448 gray→32
patch correlations match recorded values exactly, full IoU matrices agree.
Visual source/current identity is plausible for these3 cases; this is neither
held-out quality nor proof of physical approach.

## Frozen method: independent positive identity plane + unchanged measurement plane

Baseline A: frozen M3O A, TexturedGlobalWindowMotion(mode="warped"), actual
existing RAFT-small C_T_V2,12 updates/direction and same detector/camera surface.

Candidate B changes association authority, not motion measurement quality:

1. Recompute source-only normalized32x32 appearance from the EXACT raw input T
   uses. This is full native gray when its existing native-transform contract
   accepts it, otherwise explicit working-gray fallback. Do not incorrectly
   call the identity input a384-pixel native image. Keep hashes, native→working
   geometry, source ROI, normalized patch values and patch hash.
2. Reconstruct every real adjacent exposure from the selected anchor through
   current. Same ID is only a proposal. Every transition needs unique source/
   current presence, unchanged calibration/epoch, valid camera status, continuous
   actual clocks and fresh-appearance-and-reciprocal-box T metadata.
3. Independently reconstruct the FULL same-label camera-rotated IoU matrix,
   both reciprocal winners and all geometric competitors using frozen T
   associationIoU>=.25, both margins>=.12. The separate old point-association
   margin is.08; do not silently substitute it for T's stricter.12.
4. Every adjacent appearance patch must pass unchanged std3,32-patch/inset.12/
   blur3 sigma.8 and NCC>=.70. No pixel-fallback or unverified re-identification
   chain in this candidate. Birth after anchor, disappearance, reset, missing
   patch, ambiguous link or failed appearance breaks the chain. Anchor itself
   is an actual exposure, not inherited identity age; only transitions AFTER
   anchor need predecessor proof.
5. Select only the independently identified fresh/anchor pair. Both must exist
   as SUPPORTED actual A raw measurement comparisons. Retain all original point
   denominators, failed points, rival matrices and original uncertainty bounds
   unchanged in the measurement evidence. Different ID is never negative proof.
6. Reuse exact original point/NCC/cycle/RANSAC/spread/hull/shape/estimator gates:
   min9, support.70, source variance16, NCC.70, FB1.3px, RANSAC1.2px,
   bidirectional log-growth span.005, minimum current growth.0005 and long
   growth.04,3 distinct exposures,320–800ms, and all camera/epoch/gap vetoes.

This is an explicit change of association contract: independent positive
appearance/geometry chains identify a measurement source, rather than forcing
point-quality uncertainty intervals to act as object-identity evidence. It is
NOT a proof that every other physical identity is impossible. Test actual wrong
identity associations independently, including lookalikes and occlusion. No
claim that a tracker ID or resized crop measures displacement or metres.

Conceptual comparison only: [SORT](https://arxiv.org/abs/1602.00763),
[appearance-aware association](https://arxiv.org/abs/1703.07402).
Do not copy/import DeepSORT code or weights (official repository GPL3), and do
not claim this existing NCC-based method reproduces its reported performance.

## Smallest implementation and provenance

Association-only overlay consumes immutable actual A measurement surface and T
camera/identity surface. No second RAFT run is necessary for a different matching
decision on the SAME measured pair catalog. B stores references/hash-bound joins
to A's raw comparisons and positive chain certificates; it must not mutate A,
monkeypatch frozen globals or fabricate historical calls as actual inference.

Identity bank stores bounded actual exposure metadata/32-patches, at most69
adjacent exposures and<=800ms, no native frame collection or new persistent
tracker. Source selections/current IDs remain actual detector observations.
No cohort/track age can renew measurement age or carry a stale alert.

Shared actual fields are explicitly actual calls counted ONCE. B additional
RAFT calls0 does not mean standalone B needs no flow. Report standalone B time
as detector/staging/camera/A measurement plus B identity/association overhead.
Keep actual total, cold startup, proof/serialization costs separately.

comparison unmeasured, no commercial/safety/realtime superiority. Promote only
if useful recall improves without extra observed false alerts or unreviewed
