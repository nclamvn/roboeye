# Verify TIP-30

1. Run `npm run typecheck`, `npm run test:unit`, and `npm run test:airsketch-e2e`.
2. Open AirDesk. With a hand in view, confirm five yellow points; extended
   fingers must use a larger yellow ring and the markers must disappear after
   the hand leaves the frame.
3. Pinch-drag the image, then its lower/right and upper/right handles. Confirm
   move, scale and rotate. Pinch the flip controls and enable image drawing.
4. Pinch-drag through the note to select text. Trigger Copy, Cut, Delete and
   the displayed spelling correction. Confirm normal mouse/keyboard editing
   still works.
5. Switch between AirDesk and AirSketch. Only one workspace may receive hand
   input at a time.
